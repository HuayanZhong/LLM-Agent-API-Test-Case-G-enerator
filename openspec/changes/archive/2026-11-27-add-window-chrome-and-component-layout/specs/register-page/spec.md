# Spec Delta

## Purpose

为静态导出与 Electron 桌面端提供无需服务端会话的注册入口；本次把语言与主题入口从认证布局右上角移到全局窗口标题栏。

## MODIFIED Requirements

### Requirement: 静态注册页入口

系统 SHALL 在静态导出产物中提供 `/register/` 页面，并与 `/login/` 共用认证路由布局与品牌栏；主题与语言入口 MUST 由全局窗口标题栏提供，注册页 MUST NOT 随路由重复绘制入口。

#### Scenario: 直接访问注册页

- **WHEN** 用户访问 `/register/`
- **THEN** 页面渲染注册表单与产品信息，且构建产物包含 `out/register/index.html`

#### Scenario: 桌面端嵌套路由加载

- **WHEN** Electron 生产包通过 `app://` 访问 `/register/`
- **THEN** 注册页及其静态资源正常加载，不依赖 Next 服务端进程

### Requirement: 注册页响应式与主题

注册页 SHALL 复用认证布局的响应式双栏规则；主题切换按钮 MUST 由全局窗口标题栏提供，注册页 MUST NOT 再单独绘制页面内的主题入口。

#### Scenario: 桌面窗口完整展示

- **WHEN** 页面在 1280×800 的桌面窗口中渲染
- **THEN** 品牌栏与注册表单同时可见，验证码输入与发送按钮不被裁切

#### Scenario: 窄屏降级

- **WHEN** 页面在窄于 768 像素的视口中渲染
- **THEN** 品牌栏隐藏，表单上方显示产品标识，所有控件保持可用

#### Scenario: 主题按钮位于窗口标题栏

- **WHEN** 用户查看注册页
- **THEN** 窗口标题栏显示可读名称的主题切换按钮，位于系统窗口按钮左侧

### Requirement: 注册页语言入口

注册页 SHALL 复用全局窗口标题栏中的语言入口；入口与主题入口并列、位于系统窗口按钮左侧；认证布局 MUST NOT 再绘制第二套语言入口；窄屏下两个入口 MUST 仍可操作且不遮挡表单内容。

#### Scenario: 桌面宽度双入口

- **WHEN** 注册页在桌面宽度渲染
- **THEN** 语言入口与主题入口同时位于窗口标题栏，互不重叠且不被系统按钮遮挡

#### Scenario: 窄屏可操作

- **WHEN** 注册页在窄于 768 像素的视口渲染
- **THEN** 语言入口仍可聚焦与切换，且不遮挡表单
