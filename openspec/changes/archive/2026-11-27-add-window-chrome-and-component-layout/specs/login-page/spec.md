# Spec Delta

## Purpose

为静态导出与 Electron 桌面端提供无需服务端会话的邮箱登录入口；本次把语言与主题入口从认证布局右上角移到全局窗口标题栏。

## MODIFIED Requirements

### Requirement: 响应式双栏布局

登录页 SHALL 在宽度不小于 1024 像素时展示完整品牌栏与表单栏；在 768–1023 像素展示窄版品牌栏（标识与复验轨道）与表单栏；窄于 768 像素 MUST 隐藏品牌栏并在表单上方保留产品标识。所有宽度下输入与操作 MUST 可用且不出现横向溢出。

#### Scenario: 桌面窗口完整展示

- **WHEN** 页面在 1280×800 的桌面窗口中渲染
- **THEN** 完整品牌信息栏与登录表单同时可见，无需滚动即可完成登录操作

#### Scenario: 最小桌面窗口

- **WHEN** 页面在 800×600 的窗口最小尺寸下渲染
- **THEN** 窄版双栏保持可用，表单控件不被裁切，页面可纵向滚动

#### Scenario: 平板窄双栏

- **WHEN** 页面在 768–1023 像素宽度下渲染
- **THEN** 左侧显示窄版品牌栏（产品标识与四步轨道），右侧登录表单保持可用且无横向溢出

#### Scenario: 窄屏降级

- **WHEN** 页面在窄于 768 像素的视口中渲染
- **THEN** 品牌栏隐藏，表单上方显示产品标识

#### Scenario: 大屏放大

- **WHEN** 页面在 1920×1080 或更宽的窗口中渲染
- **THEN** 根字号与表单尺寸随视口放大，左栏占宽增大，页面不出现横向溢出

### Requirement: 可访问性与主题

登录页 SHALL 为每个输入提供关联标签，错误信息 MUST 可被辅助技术感知；所有操作 MUST 支持键盘完成并显示可见焦点；页面 MUST 沿用现有主题变量，在明暗主题下均保持可读。主题切换按钮 MUST 由全局窗口标题栏提供，登录页布局 MUST NOT 再单独绘制一套 fixed 入口。

#### Scenario: 标签与输入关联

- **WHEN** 辅助技术读取邮箱或密码输入框
- **THEN** 输入框具有对应的可读标签

#### Scenario: 主题按钮位于页面右上角

- **WHEN** 用户查看登录页
- **THEN** 窗口标题栏（窗口右上角区域）显示可读名称的“切换主题”按钮，位于系统窗口按钮左侧

#### Scenario: 键盘完成登录

- **WHEN** 用户仅使用键盘填写字段并提交
- **THEN** 表单可完成校验与提交，焦点状态可见

#### Scenario: 错误可被感知

- **WHEN** 校验失败
- **THEN** 字段错误与输入框关联，表单级错误通过 Toast 状态区域播报

#### Scenario: 明暗主题可读

- **WHEN** 用户切换明色或暗色主题
- **THEN** 文本、边框与焦点样式保持足够对比度，不依赖硬编码颜色

### Requirement: 登录页语言入口

登录页 SHALL 复用全局窗口标题栏中的语言切换入口；入口与主题入口并列、位于系统窗口按钮左侧；认证布局 MUST NOT 再绘制第二套语言入口；窄屏下两个入口 MUST 仍可操作且不遮挡表单内容。

#### Scenario: 桌面宽度双入口

- **WHEN** 登录页在桌面宽度渲染
- **THEN** 语言入口与主题入口同时位于窗口标题栏，互不重叠且不被系统按钮遮挡

#### Scenario: 窄屏可操作

- **WHEN** 登录页在窄于 768 像素的视口渲染
- **THEN** 语言入口仍可聚焦与切换，且不遮挡表单
