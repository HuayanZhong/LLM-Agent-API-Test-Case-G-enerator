# Spec Delta

## ADDED Requirements

### Requirement: 登录页文案本地化

登录页 SHALL 按当前界面语言呈现标题、说明、字段标签与占位符、校验错误、Toast、互链文案与可访问性标签；zh-CN 下 MUST 保持现有中文文案，en-US 下 MUST 呈现含义一致的英文文案。

#### Scenario: 中文默认文案

- **WHEN** 当前语言为 zh-CN
- **THEN** 登录页继续显示“登录工作台”“邮箱”“密码”“登录”等现有中文文案

#### Scenario: 英文界面文案

- **WHEN** 当前语言为 en-US
- **THEN** 标题、字段标签、按钮、互链与可访问性标签均显示对应英文文案

#### Scenario: 校验错误随语言

- **WHEN** 用户在 en-US 下提交空表单
- **THEN** 字段错误与表单级 Toast 均以英文呈现

#### Scenario: 切换语言保留输入

- **WHEN** 用户已填写邮箱与密码后切换语言
- **THEN** 已填写的值与“记住邮箱”勾选状态保持不变，仅文案变化

### Requirement: 登录页语言入口

登录页 SHALL 在右上角与主题入口并列展示语言切换入口；窄屏下两个入口 MUST 仍可操作且不遮挡表单内容。

#### Scenario: 桌面宽度双入口

- **WHEN** 登录页在桌面宽度渲染
- **THEN** 语言入口与主题入口同时位于右上角，互不重叠

#### Scenario: 窄屏可操作

- **WHEN** 登录页在窄于 768 像素的视口渲染
- **THEN** 语言入口仍可聚焦与切换，且不遮挡表单
